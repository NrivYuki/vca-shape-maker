# VCA Shape Maker

画像に合わせて玉形を作り、VCA（OMA / DCS）ファイルにします。商品ページのフレームの写真などから、その形を再現した VCA をブラウザの上で作れます。

[vca-guide](https://github.com/NrivYuki/vca-guide)（VCA通信の解説）・[vca-ptn-converter](https://github.com/NrivYuki/vca-ptn-converter)（玉形の変換）・[vca-lens-simulator](https://github.com/NrivYuki/vca-lens-simulator)（厚み・コバ・ヤゲンの計算）の仲間です。書き出した VCA は VCA Lens Simulator にそのまま読み込めます。

> 写真から形を「それらしく再現する」ための道具です。寸法は入力した玉形幅（A 寸）に合わせて決めるだけなので、フレームトレーサで測った値の代わりにはなりません。

## 使い方

`index.html` をブラウザで開きます。サーバーもインターネットへの接続も要りません。

設定は画面の左にあり、タブ（画像・形・寸法・VCA）で切り替えます。上の帯にはいまの条件、下の帯には玉形の寸法と、保存・コピーのボタンが出ます。

1. **画像**：画像を置くか、選ぶか、貼り付けます（Ctrl+V）。写真が傾いていれば「傾き」で水平に直します。画像を使わずに白紙の上で作ることもできます。
2. **形を置く**：
   - **クリックで自動抽出**：レンズの内側をクリックすると、リムに囲まれた範囲を取り出して形にします。背景とつながってしまうときは「色の許容値」を下げます。
   - **箱を描いて作る**：レンズを囲むように箱をドラッグすると、四隅の丸みに合わせた形を作ります。
3. **手直し**：点をドラッグ、箱の四隅と辺で伸び縮み（Shift で縦横比を保つ）、箱の中をドラッグで移動、線をダブルクリックで点を追加、点をダブルクリックで削除。四隅の丸みのスライダーは、今の箱に合わせて形を作り直します。Ctrl+Z で元に戻せます。
4. **寸法**：玉形幅 A とレンズ間距離 DBL を入れます。商品ページの「52□18」なら A = 52、DBL = 18 です。玉形高さ B は形の縦横比から決まります。
5. **書き出し**：画面下の「保存」で .vca ファイルを保存します。「コピー」で中身をクリップボードに写せます。

画像はブラウザの中だけで扱い、保存も送信もしません。書き出す VCA には形の数値だけが入ります。他社のサイトの画像は、そのサイトの利用条件に従って使ってください。

## 書き出す VCA

```
REQ=FIL
JOB=SHAPE-001
DBL=18.00
HBOX=52.00;52.00
VBOX=35.99;35.99
CIRC=153.40;153.40
FCRV=4.00;4.00
TRCFMT=1;360;E;R;F
R=2600;2601;…        （1/100 mm、15 個ずつ）
TRCFMT=1;360;E;L;F
R=…
```

- 玉形は等角度（`TRCFMT=1;360;E`）で、半径は玉形中心（外接箱の中心）から測ります。点の数は 360・400・1000・1440 から選べます（既定 360）。DCS では点の数は加工機との取り決めなので、使う加工機が受け付ける数を選んでください。
- 向きは、検者が装用者を正面から見た状態で、0° が 3 時方向、反時計回り（DCS と同じ）。右眼は +x 側が鼻側です。
- 写した眼の形をもとに、もう片方の眼は左右反転（角度 a の半径 = 180° − a の半径）して作ります。
- 改行は CR LF です。
- HBOX・VBOX・CIRC は、R レコードに書いた半径（1/100 mm に丸めた値）を等角度の点に戻して計算します。DCS の決まりどおり、書いた半径データの形と一致します。画面に出る寸法も同じ値です。

## 形の作り方

1. **自動抽出**：クリックした点の色から、似た色（許容値の範囲）を上下左右に塗り広げます。リムで止まった範囲をレンズの内側とし、映り込みなどの穴は埋めます。範囲が画像の端に届いたら「閉じていない」として止めます。範囲の重心から 720 方向へ縁までの距離を測り、少しならして輪郭にします。
2. **箱から作る**：四分円ごとのスーパー楕円 `|x/a|^n + |y/b|^n = 1` です。n が 2 で楕円、大きいほど角ばります。
3. **画面の形**：制御点を通る閉曲線（セントリペタル Catmull-Rom）です。角でも膨らみや輪ができにくい曲線です。
4. **mm への換算**：画像の y を上向きに直し、溝の補正を足したあとの幅が玉形幅 A になるように縮尺を決めます。
5. **溝の補正**：写真に見えるのはリムの内側の縁ですが、トレースする位置は溝の底（ヤゲンの山が入る位置）です。その差（既定 0.5 mm）だけ、形を法線の向きに外へ広げます。
6. **半径**：玉形中心から 360 方向へ線を引き、形との一番外側の交点までの距離を半径にします。

## できないこと

- 写真は平面なので、フレームカーブ（立体のそり）は取れません。フレームカーブは入力した値（`FCRV`）を書くだけで、立体データ（`ZFMT`）は書きません。
- 斜めから撮った写真のゆがみ（台形のゆがみ）は直しません。正面から撮った写真を使ってください。
- 縁なし（リムレス）やナイロール（ハーフリム）は、リムで囲まれていないので自動抽出できません。「箱を描いて作る」で合わせてください。

## ファイル

| ファイル | 内容 |
|---|---|
| `index.html` | 画面 |
| `shape.js` | 形の計算（閉曲線、スーパー楕円、溝の補正、半径、VCA の書き出し） |
| `extract.js` | 画像からレンズの内側を取り出して輪郭にする |
| `tests/shape.test.js` | テスト |
| `tests/ui/` | 画面の検査（Chrome をヘッドレスで動かして操作する） |
| `docs/test-items.md` | テスト項目の一覧と記録 |
| `design-ref/` | 画面の設計方針（DESIGN.md）とテンプレート |

## テスト

```sh
node --test tests/shape.test.js
```

閉曲線が制御点を通ること、スーパー楕円が箱に収まること、半径と溝の補正、左右反転、VCA の寸法と書式、画像からの輪郭の取り出し（映り込みの穴埋め、リムが切れているときの検出）を確かめます。

画面は、Chrome をヘッドレスで動かして確かめます（Node.js 22 以上）。リポジトリのフォルダで実行し、画像は OS の一時フォルダの vca-ui-check に置きます。

```sh
node tests/ui/cdp.js index.html tests/ui/steps.js
```

確かめている項目は [docs/test-items.md](docs/test-items.md) にまとめています。
